## IMPORTANT

- This extension is to be used with GM 2022.9 and future releases.
- Works with **Android** and **iOS**.

## DESCRIPTION

This extension wraps Unity's LevelPlay (ironSource) ad mediation SDK, allowing users to add and control Interstitial, Rewarded Video and Banner ads inside their application/game.

## FEATURES

- Loading and showing Interstitial and Rewarded Video ads, with placement-capping checks.
- Creating, moving and destroying Banner ads.
- GDPR consent, custom metadata and dynamic user id handling.
- Launching ironSource's Test Suite for debugging ad integrations.

## DOCUMENTATION

The full documentation of the API is included in the extension asset (included files).
