Rewarded Video

Functions for loading and showing rewarded video ads - opt-in ads that grant the player a reward for watching to completion.

Functions

This module offers a collection of functions designed to address specific tasks and provide utilities for various purposes. Explore the available functions to make the most of the functionalities provided by this module.

levelplay_rewarded_video_init

Creates the rewarded video ad instance for the given ad unit, replacing any existing one. Must be called before levelplay_rewarded_video_load.


Syntax:

levelplay_rewarded_video_init(ad_unit_id)
Argument Type Description
ad_unit_id String The rewarded video ad unit ID, from the LevelPlay dashboard.


Returns:

N/A

levelplay_rewarded_video_load

Requests a load of the previously initialized rewarded video ad. The outcome arrives asynchronously through levelplay_rewarded_callback_subscribe's callback as a LevelPlayCallbackEvent.Loaded/LoadFailed event.


Syntax:

levelplay_rewarded_video_load()


Returns:

LevelPlayError

LevelPlayError.Ok if the request was accepted, LevelPlayError.NotInitialized if levelplay_init hasn't completed, or LevelPlayError.AdNotInitialized if levelplay_rewarded_video_init hasn't been called yet.

levelplay_rewarded_video_is_placement_capped

Returns whether the given placement has reached its daily cap. Returns false for an empty or invalid placement, or if no rewarded video ad has been initialized.


Syntax:

levelplay_rewarded_video_is_placement_capped(placement_id)
Argument Type Description
placement_id String The placement to check.


Returns:

Boolean

levelplay_rewarded_video_show

Shows the rewarded video ad for the given placement.


Syntax:

levelplay_rewarded_video_show(placement_id)
Argument Type Description
placement_id String The placement to show the ad for, or "" for no placement.


Returns:

LevelPlayError

LevelPlayError.Ok if the show request was accepted, or one of LevelPlayError.ActivityUnavailable/AdNotInitialized/AdNotReady/PlacementCapped otherwise.

levelplay_rewarded_callback_subscribe

Subscribes to lifecycle callbacks for rewarded video ads. There is only one subscription at a time - calling this again replaces the previous callback.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

levelplay_rewarded_callback_subscribe(callback)
Argument Type Description
callback Function The function to call for every rewarded video lifecycle event.


Returns:

N/A


Triggers:

Callback

Fires once per lifecycle event: Loaded, LoadFailed, Displayed, DisplayFailed, Closed, Clicked, InfoChanged, or Rewarded.

Key Type Description
result LevelPlayResult The event's result. success is false only for
LoadFailed/DisplayFailed.
type LevelPlayCallbackEvent Which lifecycle event this is.
ad_info LevelPlayAdInfo Information about the ad. Absent only if the SDK provided
no ad-info object at all for this event.
reward LevelPlayReward The earned reward. Present only when type is
LevelPlayCallbackEvent.Rewarded.


Example:

levelplay_rewarded_callback_subscribe(function(_result, _type, _ad_info, _reward)
{
    switch (_type)
    {
        case LevelPlayCallbackEvent.Loaded:
            levelplay_rewarded_video_show("");
            break;
        case LevelPlayCallbackEvent.Rewarded:
            show_debug_message($"Granting {_reward.amount} x {_reward.name}");
            break;
    }
});

levelplay_rewarded_video_init("your_ad_unit_id");
levelplay_rewarded_video_load();
