Banner

Functions for creating and managing a banner ad - a small ad that stays anchored to an edge of the screen.

Functions

This module offers a collection of functions designed to address specific tasks and provide utilities for various purposes. Explore the available functions to make the most of the functionalities provided by this module.

levelplay_banner_create

Creates and loads a banner ad. Only one banner exists at a time - calling this again destroys and replaces the previous one.


Syntax:

levelplay_banner_create(ad_unit_id, size, align_h, align_v)
Argument Type Description
ad_unit_id String The banner ad unit ID, from the LevelPlay dashboard.
size LevelPlayBannerSize The banner size to request.
align_h LevelPlayBannerHAlign The horizontal alignment of the banner.
align_v LevelPlayBannerVAlign The vertical alignment of the banner.


Returns:

LevelPlayError

LevelPlayError.Ok if the request was accepted, or one of LevelPlayError.NotInitialized/ActivityUnavailable otherwise. > [!NOTE]

The banner is created asynchronously after this returns - a root-view-unavailable failure can only be discovered at that point, and is reported through levelplay_banner_callback_subscribe's callback as a LoadFailed event instead of a synchronous return value.

levelplay_banner_move

Repositions the current banner without recreating it. Does nothing if no banner exists.


Syntax:

levelplay_banner_move(align_h, align_v)
Argument Type Description
align_h LevelPlayBannerHAlign The horizontal alignment of the banner.
align_v LevelPlayBannerVAlign The vertical alignment of the banner.


Returns:

N/A

levelplay_banner_destroy

Destroys the current banner ad, if one exists. Call levelplay_banner_create again to create a new one.


Syntax:

levelplay_banner_destroy()


Returns:

N/A

levelplay_banner_callback_subscribe

Subscribes to lifecycle callbacks for the banner ad. There is only one subscription at a time - calling this again replaces the previous callback. Unlike interstitial/rewarded video, this fires repeatedly for as long as the banner exists, not just once per load/show pair.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

levelplay_banner_callback_subscribe(callback)
Argument Type Description
callback Function The function to call for every banner lifecycle event.


Returns:

N/A


Triggers:

Callback

Fires once per lifecycle event: Loaded, LoadFailed, Displayed, DisplayFailed, Clicked, Expanded, Collapsed, or LeftApplication.

Key Type Description
result LevelPlayResult The event's result. success is false only for
LoadFailed/DisplayFailed.
type LevelPlayCallbackEvent Which lifecycle event this is.
ad_info LevelPlayAdInfo Information about the ad. Absent only if the SDK provided
no ad-info object at all for this event.


Example:

levelplay_banner_callback_subscribe(function(_result, _type, _ad_info)
{
    if (_type == LevelPlayCallbackEvent.LoadFailed)
        show_debug_message($"Banner failed to load: {_result.error_message}");
});

levelplay_banner_create("your_ad_unit_id", LevelPlayBannerSize.Banner,
        LevelPlayBannerHAlign.Center, LevelPlayBannerVAlign.Bottom);

LevelPlayBannerSize

The banner sizes levelplay_banner_create can request.

These constants are referenced by the following functions:

  • levelplay_banner_create


Member Description
Banner Standard banner, 320 x 50.
Large Large banner, 320 x 90.
MediumRectangle Medium rectangular banner (MREC), 300 x 250.
Adaptive Automatically adjusts size and orientation for the current device.
