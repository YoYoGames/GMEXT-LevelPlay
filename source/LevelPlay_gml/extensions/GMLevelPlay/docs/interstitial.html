Interstitial

Functions for loading and showing interstitial ads - full-screen ads shown at natural transition points in your game.

Functions

This module offers a collection of functions designed to address specific tasks and provide utilities for various purposes. Explore the available functions to make the most of the functionalities provided by this module.

  • levelplay_interstitial_load
  • levelplay_interstitial_is_ready
  • levelplay_interstitial_is_placement_capped
  • levelplay_interstitial_show

levelplay_interstitial_init

Creates the interstitial ad instance for the given ad unit, replacing any existing one. Must be called before levelplay_interstitial_load.


Syntax:

levelplay_interstitial_init(ad_unit_id)
Argument Type Description
ad_unit_id String The interstitial ad unit ID, from the LevelPlay dashboard.


Returns:

N/A

levelplay_interstitial_load

Requests a load of the previously initialized interstitial ad. The outcome arrives asynchronously through levelplay_interstitial_callback_subscribe's callback as a LevelPlayCallbackEvent.Loaded/LoadFailed event.


Syntax:

levelplay_interstitial_load()


Returns:

LevelPlayError

LevelPlayError.Ok if the request was accepted, LevelPlayError.NotInitialized if levelplay_init hasn't completed, or LevelPlayError.AdNotInitialized if levelplay_interstitial_init hasn't been called yet.

levelplay_interstitial_is_placement_capped

Returns whether the given placement has reached its daily cap. Returns false for an empty or invalid placement, or if no interstitial ad has been initialized.


Syntax:

levelplay_interstitial_is_placement_capped(placement_id)
Argument Type Description
placement_id String The placement to check.


Returns:

Boolean

levelplay_interstitial_show

Shows the interstitial ad for the given placement.


Syntax:

levelplay_interstitial_show(placement_id)
Argument Type Description
placement_id String The placement to show the ad for, or "" for no placement.


Returns:

LevelPlayError

LevelPlayError.Ok if the show request was accepted, or one of LevelPlayError.ActivityUnavailable/AdNotInitialized/AdNotReady/PlacementCapped otherwise.

levelplay_interstitial_callback_subscribe

Subscribes to lifecycle callbacks for interstitial ads. There is only one subscription at a time - calling this again replaces the previous callback.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

levelplay_interstitial_callback_subscribe(callback)
Argument Type Description
callback Function The function to call for every interstitial lifecycle event.


Returns:

N/A


Triggers:

Callback

Fires once per lifecycle event: Loaded, LoadFailed, Displayed, DisplayFailed, Closed, Clicked, or InfoChanged.

Key Type Description
result LevelPlayResult The event's result. success is false only for
LoadFailed/DisplayFailed.
type LevelPlayCallbackEvent Which lifecycle event this is.
ad_info LevelPlayAdInfo Information about the ad. Absent only if the SDK provided
no ad-info object at all for this event.


Example:

levelplay_interstitial_callback_subscribe(function(_result, _type, _ad_info)
{
    switch (_type)
    {
        case LevelPlayCallbackEvent.Loaded:
            levelplay_interstitial_show("");
            break;
        case LevelPlayCallbackEvent.LoadFailed:
            show_debug_message($"Interstitial failed to load: {_result.error_message}");
            break;
    }
});

levelplay_interstitial_init("your_ad_unit_id");
levelplay_interstitial_load();
