levelplay_init

This function initialises the LevelPlay SDK. You should call it once, before any other LevelPlay function. It requires the AndroidAppKey or the iOSAppKey option of the extension to be set for the current platform. See Extension Options.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

levelplay_init(callback)
Argument Type Description
callback Function The function to call once the initialisation completes or fails.


Returns:

LevelPlayError

LevelPlayError.Ok if the initialisation request was accepted, or an error code if it was rejected outright, for example because the app key is missing. In that rejected case callback is never called.


Triggers:

Callback

Called once, when the SDK finishes starting up or fails to do so. It is not called if levelplay_init itself returned an error synchronously.

Key Type Description
result LevelPlayResult The outcome of the initialisation.


Example:

levelplay_init(function(_result)
{
    if (_result.success)
        show_debug_message("LevelPlay initialized");
    else
        show_debug_message($"LevelPlay failed to initialize: {_result.error_message}");
});

LevelPlayCallbackEvent

The lifecycle events that an ad callback can be called with. Which subset of these a given ad type uses is documented on the _load function of that type, or on _callback_subscribe for a banner.

These constants are referenced by the following functions:

  • levelplay_banner_callback_subscribe
  • levelplay_interstitial_create
  • levelplay_rewarded_video_create


Member Description
Loaded The ad finished loading and is ready to be shown.
LoadFailed The ad failed to load. LevelPlayResult.success is false for this
event.
Displayed The ad was displayed, which is the equivalent of an impression.
DisplayFailed The ad failed to display. LevelPlayResult.success is false for
this event.
Closed The ad view was closed. Interstitial and rewarded video only.
Clicked The user clicked the ad.
InfoChanged The ad info was updated, which happens when another ad has loaded with a
higher CPM or rate. Interstitial and rewarded video only.
Rewarded The user finished watching a rewarded video and should be rewarded.
LevelPlayReward is only populated for this event. Rewarded video only.
Expanded The banner was expanded to fullscreen. Banner only.
Collapsed The banner was restored from fullscreen. Banner only.
LeftApplication The user clicked the banner and was navigated out of the app. Banner only.

LevelPlayError

The synchronous error codes that are returned by most functions in this extension. They describe why a call was rejected outright, for example because it was made before the initialisation completed, or with no ad loaded. A failure that is reported by the SDK itself after a call was accepted arrives asynchronously through a LevelPlayResult instead.

These constants are referenced by the following functions:

  • levelplay_banner_create
  • levelplay_init
  • levelplay_interstitial_load
  • levelplay_interstitial_set_callback
  • levelplay_interstitial_show
  • levelplay_rewarded_video_load
  • levelplay_rewarded_video_set_callback
  • levelplay_rewarded_video_show


Member Description
Ok The call was accepted.
NotInitialized levelplay_init has not completed successfully yet.
AdNotReady The ad has not finished loading yet, or it has already been shown.
PlacementCapped The given placement has reached its daily cap.
ActivityUnavailable The current Android activity or iOS view controller is not available.
RootViewUnavailable Banner only. The root view was unavailable when the banner tried to
attach itself. No function ever returns this value, as the failure that it describes can only be
discovered after levelplay_banner_create has already returned. It is reported as a
LoadFailed event through the banner callback instead, and the reason is given in
result.error_message. See levelplay_banner_callback_subscribe.
MissingAppKey The AndroidAppKey or the iOSAppKey option of the extension is not set
for the current platform.
InvalidHandle Interstitial and rewarded video only. The handle is not a live handle from
the matching _create function, or it has already been destroyed.

LevelPlayResult

The uniform success or failure envelope that is given to every asynchronous callback in this extension. Both error_message and sdk_error_code are absent when the operation succeeded. The sdk_error_code member carries the ad error code of the SDK itself, and it is only present when the failure came from a LoadFailed or a DisplayFailed ad lifecycle event, which means that it is absent for every other event and for the failures of levelplay_init.

This struct is referenced by the following functions:

  • levelplay_banner_callback_subscribe
  • levelplay_init
  • levelplay_interstitial_create
  • levelplay_rewarded_video_create


Member Type Description
success Boolean Whether the operation succeeded.
error_message String The error message of the SDK itself. This is only present on a
failure.
sdk_error_code Real The raw ad error code of the SDK. This is only present on a
LoadFailed or a DisplayFailed event that carried an error object from the SDK.

LevelPlayAdInfo

Information about a specific ad instance or impression, which is given alongside most LevelPlayCallbackEvent events. It mirrors the ad info object of the LevelPlay SDK itself, and any field that the SDK did not supply for a given event is absent. The width and height members are the exception, as they are 0 rather than absent whenever the SDK reported no size for the ad.

Note

A LoadFailed event carries no ad info object from the SDK at all, and the two platforms differ in what they pass in its place. On iOS the ad unit ID that the SDK reports separately is carried through as a partial struct, so unit_id is present, width and height are 0 and every other field is absent. On Android the whole ad_info argument is undefined for that event, so you should test it with is_undefined before you read anything from it.

This struct is referenced by the following functions:

  • levelplay_banner_callback_subscribe
  • levelplay_interstitial_create
  • levelplay_rewarded_video_create


Member Type Description
width Real The width of the ad, in pixels. This is 0 if the width is unknown.
height Real The height of the ad, in pixels. This is 0 if the height is unknown.
format String The ad format, as reported by the SDK.
network String The mediated network that served the ad.
unit_id String The ad unit ID.
unit_name String The display name of the ad unit, as it is configured on the
dashboard.
placement_name String The name of the placement that the ad was requested for.
country String The country that the impression is attributed to.
precision String The revenue precision, as reported by the SDK.
revenue Real The estimated revenue for this impression.
